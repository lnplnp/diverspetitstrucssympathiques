# Divers Petits Trucs Sympathiques

## Constante de Kaprekar (6174)

Ce dossier contient une page web interactive qui démontre la constante de Kaprekar, également connue sous le nom de 6174. Cette constante est un phénomène mathématique fascinant où, en appliquant un processus spécifique à un nombre à 4 chiffres (non tous identiques), on obtient toujours le nombre 6174 après un certain nombre d'itérations.

Pour utiliser la page, entrez un nombre à 4 chiffres (par exemple, 1000, 1110, 3524) dans le champ de saisie et cliquez sur le bouton "Calculer". La page affichera alors les étapes intermédiaires du calcul jusqu'à l'obtention de la constante 6174.
